# Week 1 - Project Module 2 (Extra): SOC Wireshark Labs

## Overview
Acting as a SOC Analyst, I successfully completed 6 live browser-based Wireshark labs. Each lab contained 10 tasks focused on investigating network captures, finding attackers, identifying hidden data, extracting plain text passwords, and investigating VoIP scam calls.

## Labs Completed
1. **Lab 3: Identify the Attacker's IP** (Analyzed traffic to find the attacker's IP)
2. **Lab 4: Follow TCP Stream 1** (Rebuilt a TCP conversation to read plain text chat)
3. **Lab 5: Follow TCP Stream, Part 2** (Practiced finding hidden data in streams)
4. **Lab 6: HTTP Plain Text Credentials** (Extracted clear text usernames/passwords)
5. **Lab 7: Catch the Brute Force Attacker** (Spotted repeated login attempts on an FTP server)
6. **Lab 8: Catch the Call Scammer** (Investigated and played back a VoIP call)
